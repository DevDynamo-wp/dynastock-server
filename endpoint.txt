Créer une boutique (remplace le token par celui obtenu en Phase 3) :

bash
curl -X POST http://127.0.0.1:8000/api/stores/ \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer TON_ACCESS_TOKEN" \
{
    "name":"Boutique Porto-Novo",
    "city":"Porto-Novo",
    "address":"Quartier Houinmè"
}

Réponse attendue : 201, avec "role": "owner" dans la réponse.

Lister mes boutiques :

bash
curl http://127.0.0.1:8000/api/stores/ \
